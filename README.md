# S7 Chat cho Windows — bộ cài

## ⬇ [Tải bản mới nhất](https://github.com/szen7dev/s7-chat-desk-releases/releases/latest)

Mở link, kéo xuống **Assets**, tải `S7-Chat-Setup-<phiên bản>.exe` rồi chạy.
Windows cảnh báo (phần mềm chưa ký số) thì bấm **"Thông tin thêm"** → **"Vẫn chạy"**.

Repo này chỉ chứa file cài và là nguồn tự cập nhật của phần mềm — đừng xoá các file `latest.yml` / `.blockmap` trong bản phát hành.
